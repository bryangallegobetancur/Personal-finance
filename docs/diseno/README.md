# Diseño visual

La interfaz conserva cuatro temas y comparte componentes semánticos. La fuente vigente es [`src/index.css`](../../src/index.css), junto con [`ThemeContext.tsx`](../../src/contexts/ThemeContext.tsx) y [`tailwind.config.js`](../../tailwind.config.js).

| Tema | Clase | Identidad |
| --- | --- | --- |
| Vidrio | `v3` | Degradado menta, azul y lavanda; superficies translúcidas; texto azul oscuro |
| Menta | `v5` | Verde suave, bordes discretos y controles redondeados |
| Aurora | `v7` | Fondo oscuro, luces de color y acción primaria blanca |
| Profundo | `v10` | Azul marino con acento cian |

La presentación usa Vidrio: colores `#dff0ea`, `#cfe0f2`, `#e7dcf3`, texto `#10203a` y acento `#2a7d6b`. El texto, los diagramas y la tabla son editables en PowerPoint. El fondo es una imagen decorativa generada con IA y la evidencia visual es una captura real de la demo pública. Arial se utiliza en las diapositivas por disponibilidad y portabilidad; la aplicación mantiene Inter.

Las propuestas de diseño anteriores se conservan en `historico/` como antecedentes. Pueden mencionar tecnologías o estados de interfaz que ya no corresponden al producto. No se consideran instrucciones vigentes de despliegue ni evidencia de funcionalidades.
